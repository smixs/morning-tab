# Ежедневная рутина

Предлагать после первого выпуска, когда пользователь посмотрел страницу и сказал «ок». Ставить только после его согласия: каждый запуск — это сессия агента, она расходует лимит подписки или токены (источники при этом бесплатные). Цену назвать в предложении.

## 1. Предложение

Один вопрос: «Ставить ежедневный выпуск в 07:00 (<часовой пояс>)?» с вариантами «да, в 07:00», «да, в другое время», «нет». Ссылка остаётся той же, поэтому отдельная доставка не нужна; если у агента есть канал уведомлений (push, мессенджер, почта), спросить, слать ли туда ссылку с одной фразой о главном.

## 2. Выбор исполнителя

| Окружение | Как поставить | Что важно |
|---|---|---|
| Агент со встроенным планировщиком (облачные рутины Claude Code через `/schedule`, автоматизации Codex) | создать задачу с промптом из раздела 3 | облаку недоступны локальные входы CLI: токен площадки (`references/publish.md`) задать в секретах рутины, скилл должен быть доступен там же |
| Машина пользователя, включённая утром, macOS | `launchd`, файл ниже | у `launchd` пустой `PATH`, поэтому путь к Bun, Node и агенту задаётся явно |
| Машина пользователя, Linux | `cron`, строка ниже | то же про `PATH` |

Ноутбук, который утром закрыт, выпуск пропустит: тогда предложить облачный планировщик или включённый круглосуточно компьютер.

## 3. Промпт рутины

```
Выпуск «Утренней вкладки» (скилл morning-tab), рабочая папка <папка темы>.
Режим рутины: вопросов не задавать. Если pre-flight, сбор или вёрстка дали FAIL —
остановиться и последней строкой написать причину и что исправить.
```

## 4. Локальный запуск

Команда агента без человека (Claude Code; для Codex — `codex exec "<промпт>"`):

```
claude -p "<промпт>" --allowedTools "Bash,Read,Write,Edit" >> <папка темы>/routine.log 2>&1
```

macOS: `~/Library/LaunchAgents/com.morning-tab.<slug>.plist`, затем `launchctl load` этого файла.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.morning-tab.SLUG</string>
  <key>ProgramArguments</key><array><string>/bin/zsh</string><string>-lc</string><string>КОМАНДА АГЕНТА</string></array>
  <key>EnvironmentVariables</key><dict><key>PATH</key><string>ВЫВОД echo $PATH ИЗ ТЕРМИНАЛА ПОЛЬЗОВАТЕЛЯ</string></dict>
  <key>StartCalendarInterval</key><dict><key>Hour</key><integer>7</integer><key>Minute</key><integer>0</integer></dict>
</dict></plist>
```

Linux: `crontab -e`, строка `0 7 * * * PATH=<PATH пользователя> <команда агента>`.

## 5. Проверка до слов «рутина стоит»

- [ ] запустить рутину вручную один раз (`launchctl start com.morning-tab.<slug>`, тестовый запуск в планировщике агента или команду из раздела 4);
- [ ] в `routine.log` или в истории планировщика нет FAIL;
- [ ] по ссылке открылась страница с сегодняшней датой и новым временем выпуска;
- [ ] сообщить пользователю время, исполнителя и как отключить: `launchctl unload <plist>` и удалить файл, `crontab -e` и удалить строку или удалить задачу в планировщике агента.
