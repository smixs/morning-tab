# Первый запуск темы

Цель: рабочая папка темы с проверенным `config.json`, согласованным с пользователем. Тема и источники задают всё содержимое страницы, поэтому их называет пользователь: страница по угаданной теме бесполезна, а заметит он это только после публикации.

## 1. Узнать окружение

Запустить `scripts/preflight.sh` без конфига. FAIL по Bun, зависимостям, браузеру или сети исправить до интервью (или попросить пользователя: способ указан в выводе). Так интервью не придётся прерывать на середине.

## 2. Интервью: один раунд вопросов

Задать все вопросы одним раундом (инструментом вопросов агента, если он есть; иначе одним сообщением со списком). Тема и источники обязательны; без ответа на них дальше не идти.

| Вопрос | Обязателен | Если пользователь не знает |
|---|---|---|
| Тема: о чём страница, что в неё входит и что нет | да | — |
| Источники: свой список (сайты, блоги, сабреддиты, каналы) или «подбери сам» | да | подобрать по разделу 4 и показать список на утверждение |
| Язык страницы | нет | язык, на котором пишет пользователь |
| Название и подзаголовок | нет | предложить два варианта |
| Город для погоды | нет | без погоды (поле `city` не заполнять) |
| Куда публиковать | да | площадка, где pre-flight уже видит вход; иначе варианты из `references/publish.md` |

## 3. Рабочая папка

Создать `~/morning-tab/<slug>/` (slug — латиницей из темы) или папку, которую назвал пользователь. Внутри: `config.json` и `out/`. Папка живёт отдельно от скилла: обновление скилла не стирает настройки, а несколько тем не мешают друг другу.

Скопировать ближайший пример из `config/` в `<папка>/config.json` и заполнить:

| Поле | Что писать |
|---|---|
| `title`, `tagline`, `topline` | из интервью; тон нейтральный |
| `lang`, `locale`, `timezone` | например `ru`, `ru-RU`, `Europe/Moscow` |
| `city` | `{name, lat, lon}` или убрать поле |
| `keywords` | 8–15 слов темы на английском и на языке страницы; поднимают релевантные материалы в главные |
| `windowHours` | 24; для медленных тем 48–72 |
| `sections` | 3–7 рубрик `{id, title}`; каждый `source.section` ссылается на одну из них |
| `sources` | `{name, url, section, limit, type?, windowHours?, boost?}`; `boost` 40–100 для первоисточников темы |
| `publish` | `{target, project?, url?}`; `url` вписать после первой публикации |
| `labels` | подписи интерфейса для языков кроме русского (ключи в `scripts/config.ts`, `DEFAULT_LABELS`) |

## 4. Подбор источников

Свои источники пользователя идут первыми. Когда нужно подобрать самому, собрать 5–10 источников минимум из трёх типов:

| Тип | URL | Когда брать |
|---|---|---|
| Google News | `https://news.google.com/rss/search?q=<запрос>+when:1d&hl=<язык>&gl=<страна>&ceid=<страна>:<язык>` | всегда, 1–3 запроса; работает для любой темы и языка, поэтому страница не останется пустой |
| Сайт или блог | RSS/Atom сайта: `/feed`, `/rss`, `/feed.xml`, `/atom.xml` или `<link rel="alternate" type="application/rss+xml">` в HTML | первоисточники темы, с `boost` |
| Reddit | `https://www.reddit.com/r/<sub>/top/.rss?t=day` | сообщества темы; с серверов часто 403/429 |
| Hacker News | `https://hnrss.org/newest?q=<слова>&points=20`, `"type": "hn"` | технические темы |
| arXiv | `https://rss.arxiv.org/rss/<категория>` | научные темы |
| YouTube | `https://www.youtube.com/feeds/videos.xml?channel_id=<id>` | каналы темы |
| GitHub Trending | `https://github.com/trending?since=daily`, `"type": "github-trending"` | темы про код |

X (Twitter) и платный поиск требуют платного API: предлагать только с ценой и после явного согласия пользователя. Telegram-каналы без RSS-моста не подключаются; мост берётся только по ссылке пользователя.

## 5. Проверка источников

Запустить сбор (команда в SKILL.md, шаг «Сбор») и прочитать строки статуса:

- [ ] источник с `ошибка` или `ПУСТО`: исправить URL, расширить его `windowHours` или убрать;
- [ ] материалов всего не меньше 12 (главная, вторая, четыре заметки и рубрики); меньше — добавить запрос Google News или расширить `windowHours`;
- [ ] в первых 10 материалах `out/items.json` (по `score`) есть материалы по теме; посторонние — сузить запрос или убрать источник.

## 6. Согласование

Показать пользователю одним сообщением: тема, название, список источников с числом материалов у каждого, площадку. Получить «ок» и перейти к выпуску.
